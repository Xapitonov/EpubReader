## О проекте:

Это компактная читалка Epub для Android, основанная на [EPUB3Reader](https://github.com/pettarin/epub3reader) с использованием [Epublib](https://github.com/psiegman/epublib). Она обновлена для совместимости с новыми версиями Android (и несколько функций убрано). Остальное осталось тем же, что и в оригинальном проекте.

Особенности:


* Открытие Epub файла
* Показ метаданных
* Показ содержимого (TOC)
* Поддержка внутренних ссылок Epub 
* Изменение цвета фона 
* Изменение цвета текста 
* Изменение шрифта
* ...

Недостатки:

* Нет поддержки библиотеки
* Для больших файлов требуется время для загрузки Epub файла
